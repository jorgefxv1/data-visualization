for Repetição definida

Estrutura FOR

Use quando você sabe quantas vezes precisa repetir, ou quando precisa percorrer cada item de uma lista, range ou string.

Sintaxe

for variavel in sequencia:
    bloco_de_codigo

Quando usar
  • Percorrer listas de notas, nomes, valores
  • Repetir N vezes com range(N)
  • Percorrer cada letra de uma string
  • Processar cada linha de um arquivo
Exemplos de sequências
  • range(5) → 0, 1, 2, 3, 4
  • range(1, 11) → 1 até 10
  • [7, 8, 9, 6, 10] → lista
  • "Python" → P, y, t, h, o, n
Vantagem principal

Com uma única linha você processa qualquer quantidade de itens — 5, 500 ou 5 milhões.

Insight

O mesmo código que calcula a média de 5 alunos funciona para 5.000 alunos — basta a lista ter mais itens. O FOR se adapta automaticamente ao tamanho da sequência.

Atenção

O FOR percorre a sequência na ordem e garante que cada item seja processado exatamente uma vez. Não é possível "pular para frente" — use índices se precisar de acesso aleatório.

while Repetição por condição

Estrutura WHILE

Use quando não sabe quantas repetições serão necessárias — o loop continua até a condição se tornar False.

Sintaxe

while condicao:
    bloco_de_codigo

Quando usar
  • Repetir até acertar uma senha
  • Enquanto houver saldo na conta
  • Esperar entrada correta do usuário
  • Número de repetições imprevisível
Como funciona
  • Verifica a condição antes de cada iteração
  • Se True → executa o bloco
  • Se False → sai do loop
  • A condição deve mudar dentro do bloco!
Perigo

Se a condição nunca se tornar False, o programa trava. Sempre garanta que a variável de controle seja atualizada dentro do loop.

4    if senha == "python":
5        print("Acesso liberado!")

7    tentativas += 1

Insight

O WHILE é ideal para situações do mundo real onde você não controla quantas tentativas o usuário vai precisar. Sistemas de login, validação de formulários e downloads usam esse padrão.

Atenção

A condição é verificada antes de cada iteração. Se a condição já começa como False, o bloco nunca executa — diferente do do...while de outras linguagens.

∞ Perigo

Loop Infinito

Ocorre quando a condição do while nunca se torna False. O programa trava e só pode ser encerrado à força.

⚠️

O programa trava e não responde

Um loop infinito consome 100% do processador e não libera o programa. A causa mais comum é esquecer de atualizar a variável de controle dentro do bloco do while.

❌ Código errado — loop infinito
i = 0
while i < 5:
    print(i)
    # ← i nunca muda!

⟳ rodando para sempre...
✅ Código correto
i = 0
while i < 5:
    print(i)
    i += 1 # ← i cresce a cada iteração

Saída: 0, 1, 2, 3, 4 → encerra.
Como identificar

Se seu programa não responde ou o terminal fica preso sem imprimir nada, suspeite de um loop infinito. No terminal, use Ctrl + C para interromper forçadamente.

Checklist antes de rodar

Antes de executar qualquer while, verifique: (1) A variável de controle é atualizada dentro do loop? (2) A condição pode realmente se tornar False? (3) Existe um caminho de saída garantido?

break / continue Controle de fluxo

Break & Continue

Palavras-chave especiais que controlam o fluxo dentro de um loop — uma encerra o loop, a outra pula para a próxima iteração.

🛑 break — encerra o loop imediatamente

Quando o Python encontra um break, sai do loop na hora — ignora as iterações restantes e continua o código após o bloco.

notas = [7, 4, 8, 2, 9]
for nota in notas:
    if nota < 5:
        break # para tudo!
    print(nota)

Saída: 7 → encontrou 4 (menor que 5) → STOP
⏭ continue — pula para a próxima iteração

Quando o Python encontra um continue, ignora o restante do bloco apenas nessa iteração e volta para o início do loop.

notas = [7, 4, 8, 2, 9]
for nota in notas:
    if nota < 5:
        continue # pula notas baixas
    print(nota)

Saída: 7, 8, 9 → 4 e 2 foram pulados
Diferença-chave

break termina o loop inteiro. continue apenas pula aquela iteração — o loop continua normalmente para os próximos itens. Pense: break = porta de saída, continue = pular uma linha da fila.

Uso no mundo real

break é muito usado em buscas — quando você encontra o que procura, não precisa continuar varrendo. continue é usado para filtrar dados — ignorar registros inválidos, vazios ou que não atendem a um critério.

for vs while Guia de escolha

Quando usar FOR ou WHILE?

A escolha certa torna o código mais legível e seguro. Aqui está o guia de decisão.

Situação Use FOR Use WHILE
Quantidade de repetições Conhecida antes de começar Imprevisível / depende de evento
Percorrer sequência ✓ Ideal — lista, range, string Possível, mas menos natural
Depende de entrada do usuário Não recomendado ✓ Ideal
Risco de loop infinito Nenhum — sequência define o fim Alto se a condição não mudar
Exemplos típicos Média de notas, processar lista, contar Login, validação, aguardar evento
FOR — Soma de 5 notas (quantidade conhecida)
notas = [7, 8, 6, 9, 10]
soma = 0

for nota in notas:
    soma += nota

print(soma / len(notas))

# Claro, seguro, sem risco de travar
WHILE — Senha (quantidade imprevisível)
acesso = False

while not acesso:
    s = input("Senha: ")
    if s == "python":
        acesso = True

print("Bem-vindo!")

# Só para quando o usuário acertar

Questões dissertativas
1Dissertativa

Qual é a diferença entre for e while? Em que situação você escolheria cada um?

For é usado quando sabemos quantas repetições serão necessárias — percorre uma sequência (lista, range, string) e encerra automaticamente quando a sequência termina.

While é usado quando não sabemos quantas repetições serão necessárias — o loop continua enquanto uma condição for verdadeira e só encerra quando ela se torna falsa.

Exemplo: use for para calcular a média de 30 alunos (quantidade definida). Use while para validar a senha de um usuário (não sabemos quantas tentativas ele vai precisar).

2Dissertativa

O que é um loop infinito? Como ele ocorre e como pode ser evitado?

Um loop infinito ocorre quando a condição do while nunca se torna False — o bloco fica executando para sempre e trava o programa.

A causa mais comum é esquecer de atualizar a variável de controle dentro do loop. Por exemplo: i = 0 / while i < 5: print(i) — como i nunca muda, a condição sempre será True.

Para evitar: sempre garanta que a variável de controle seja modificada dentro do bloco (i += 1), ou que exista um break com condição de saída garantida.

3Dissertativa

Explique o que fazem as palavras-chave break e continue dentro de um loop. Qual a diferença entre elas?

break encerra o loop imediatamente — quando o Python encontra um break, sai do loop por completo e continua o código após o bloco.

continue pula apenas a iteração atual — ignora o restante do bloco naquela repetição e volta ao início do loop para processar o próximo item.

Diferença principal: break termina o loop inteiro; continue apenas pula aquela iteração específica.

4Dissertativa

O que significa o princípio DRY (Don't Repeat Yourself) e como as estruturas de repetição ajudam a aplicá-lo?

DRY (Don't Repeat Yourself) é um princípio de programação que diz: nunca escreva o mesmo código duas vezes. Código duplicado é difícil de manter — se você precisar corrigir um erro, terá que corrigir em todos os lugares.

As estruturas de repetição aplicam DRY permitindo que um único bloco de código processe qualquer quantidade de dados. Em vez de escrever 30 blocos para calcular 30 médias, você escreve uma vez e usa um for para repetir automaticamente.

5Dissertativa

Analise o código: soma = 0 / for i in range(1, 6): / soma += i / print(soma). O que será impresso e por quê?

Será impresso 15.

range(1, 6) gera a sequência 1, 2, 3, 4, 5. O loop soma cada valor a soma: 0+1=1, 1+2=3, 3+3=6, 6+4=10, 10+5=15. Ao final, print(soma) exibe 15.

Observação: o print está fora do loop (sem indentação), então é executado apenas uma vez — após todas as 5 iterações terminarem.
